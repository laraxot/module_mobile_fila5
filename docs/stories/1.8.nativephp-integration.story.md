# 1.8 NativePHP Integration Story

## Titolo: Integrazione con NativePHP per app nativa mobile

## Descrizione
Integrare il modulo Mobile con NativePHP per creare un'app nativa iOS/Android dal codice PHP/Laravel.

## Obiettivi
1. Configurare NativePHP nel progetto Laravel
2. Creare la struttura dell'app NativePHP
3. Integrare Blade components con NativePHP views
4. Implementare autenticazione nativa
5. Supportare offline storage con SQLite locale
6. Creare build pipeline con Bifrost

## Documentazione Tecnica
- NativePHP usa Blade per generare view native SwiftUI/Jetpack Compose
- Nessun webview necessario - "SuperNative"
- App sotto i 50MB
- Supporta Livewire, Filament, Tailwind, Alpine

## Triggers
- `php artisan nativephp:build`
- `php artisan nativephp:serve`
- `php artisan nativephp:ios`
- `php artisan nativephp:android`

## Risultati
- App nativa mobile
- Build automatico con Bifrost
- Integrazione completa con modulo Restaurant
- Sync offline
- Push notifications
