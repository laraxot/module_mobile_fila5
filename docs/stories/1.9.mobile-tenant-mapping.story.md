# 1.9 Mobile-Tenant Mapping Story

## Titolo: Mappatura Mobile e Tenant per modulo Restaurant

## Descrizione
Definire come il modulo Mobile si collega al sistema di multi-tenancy Restaurant.

## Mappatura
- **Company** (Restaurant) → **Tenant** (Tenant module)
- **CompanyConfig** → Tenant settings per mobile
- **Tables** → Tenant-scoped tables
- **Orders** → Tenant-scoped orders
- **Waiters** → Tenant-scoped users
- **Menu** → Tenant-scoped menu items

## Triggers
- `Modules/Tenant` esistente
- `Modules/Restaurant` con Company/CompanyConfig
- `Modules/Mobile` nuovo modulo

## Risultati
- Clear tenant isolation
- Mobile access per tenant
- Waiter auth per tenant
- Order sync per tenant

## Success Metrics
- Zero data leak tra tenant
- 99.9% sync success rate
- Latenza <2s su 4G
