# 1.10 Legacy to Mobile Migration Story

## Titolo: Migrazione da legacy PHP a modulo Mobile

## Descrizione
Convertire la legacy mappa tavoli e sistema ordini verso il nuovo modulo Mobile.

## Legacy Components
- `/var/www/_bases/ristorante/views/ordini/map.php` (386 righe)
- `/var/www/_bases/ristorante/views/admin/tables.php` (487 righe)

## Mapping to New
- Map.php → `Modules/Mobile/resources/views/layouts/app.blade.php`
- Tables.php → `Modules/Mobile/resources/views/mobile/tables.blade.php`
- DiningTables → App\Models\DiningTable (Restaurant module)
- Orders → App\Models\Order (Restaurant module)

## Migration Phases
1. Audit legacy components (COMPLETATO)
2. Creare modulo Mobile base (IN CORSO)
3. Creare views mobile (RESTO DA FARE)
4. Migrar logica ordine
5. Implementare sync offline
6. Test con cameriere reale

## Technical Details
- Usa stesse colonne/colonne geometry (160×190, card 160px)
- Mantiene griglia 6/8 colonne
- Risoluzione responsive (320px min-width)
- Supporto touch >7mm target

## Success Metrics
- Funzionalità equivalenti legacy
- Aumentato 20% velocità
- Supporto offline 100%
- Bug report <5 al mese

## Verifica (2026-09-17)

- Il mapping `Map.php → Modules/Mobile/resources/views/layouts/app.blade.php` non
  corrisponde al percorso reale: la view esiste come
  `Modules/Mobile/resources/views/mobile/app.blade.php` (non c'è una cartella
  `layouts/`). Correggere il riferimento se questa story viene ripresa come base per
  altro lavoro.
- Le fasi elencate sopra (COMPLETATO/IN CORSO/RESTO DA FARE) riflettono lo stato al
  momento della stesura della story, non quello attuale: vedere
  [1.11](1.11.mobile-module-boundary.story.md) e [docs/README.md](../README.md) per
  la mappa del codice verificata più di recente.
