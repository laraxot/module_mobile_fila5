# Manuale utente Mobile

Integra il [manuale actor-oriented](../manuale-uso-attori.md). Mobile espone contratti e gateway per client mobili.

## Attori e uso

| Attore | Uso verificato |
|---|---|
| Utente/utente di gruppo | Usa le API mobili quando il contratto e l'autorizzazione lo consentono. |
| Operatore/admin | Configura o monitora integrazioni disponibili. |
| Super-admin | Governa accessi e configurazione globale. |

Le capacità specifiche del client devono essere verificate contro il contratto API.
